# Provenance

This app's design and code are its own. No code was copied from another project.

- Its shape follows the objectives and key results practice: objectives in a period, measurable
  key results with check-ins and confidence, and alignment between objectives.
- Projects and portfolios are the Projects app's, linked through the platform's records.
- Key results measured from the records run a Studio query of one measure with the platform's
  Studio engine, as the Metrics app's metrics are defined; the code is this app's own.
